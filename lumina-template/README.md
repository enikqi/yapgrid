# Lumina — Digital Agency & Personal Portfolio HTML Template

A premium, fully responsive HTML template for creative studios, agencies and
personal portfolios. 16 pages, one consistent design system, no framework
beyond Bootstrap 5.

## Getting started

The generated HTML files at the root are the template. Open any of them in a
browser — there is nothing to install and no build step to run.

```bash
# optional: serve locally so relative paths behave exactly as in production
npx serve .
```

### Editing

Two ways, pick whichever suits you:

**Edit the HTML directly.** The files at the root are plain, readable HTML.
Change them and you're done. This is how most people will use the template.

**Or use the source layout.** `src/` keeps the shared header and footer in one
place so a nav change doesn't mean editing 16 files:

```
src/partials/head.html      <head> contents, meta tags, font + CSS links
src/partials/header.html    navbar, mobile drawer, preloader, cursor
src/partials/footer.html    CTA band, footer, back-to-top
src/partials/scripts.html   vendor + template script tags
src/pages/<name>.html       the body content of one page
```

Then regenerate:

```bash
node build.js
```

`build.js` reads the page list in its `MANIFEST` array — title and meta
description live there, alongside the filename.

## Customising

### Colours and type

Everything is a CSS custom property at the top of `assets/css/style.css`:

```css
:root {
  --lu-accent: #ff4d2e;        /* one accent drives the whole template */
  --lu-bg: #0a0a0c;
  --lu-text: #f4f4f1;
  --lu-font-display: "Syne", …;
  --lu-font-body: "Inter", …;
}
```

Change `--lu-accent` and the buttons, links, icons, badges, focus rings and
gradients all follow. The light theme overrides the same names under
`[data-theme="light"]`.

Type scales use `clamp()`, so headings resize fluidly between mobile and
desktop without breakpoint-by-breakpoint overrides.

### Swapping the fonts

The three families are self-hosted in `assets/fonts/`, with `@font-face` rules
generated into `assets/css/fonts.css`. To change them, edit the `FAMILIES`
array in `tools/vendor.js`, install the matching `@fontsource` package and
re-run it — then update `--lu-font-display` / `--lu-font-body` in `style.css`.

### Replacing the artwork

The SVGs in `assets/img/` are abstract placeholders generated by
`tools/gen-assets.js`. Swap them for real photography by replacing the files —
the `<img>` tags already carry `width`, `height` and `loading="lazy"`, so
layout stability is preserved as long as you keep the aspect ratios
(4:3 for work, 16:10 for posts, 3:4 for portraits).

## Components

| Component | Where | Notes |
|---|---|---|
| Sticky navbar | all pages | blurs on scroll, hides down / shows up |
| Mobile drawer | all pages | full-screen, Escape closes, focus-safe |
| Theme toggle | all pages | persists via `localStorage`, no flash |
| Smooth scroll | all pages | Lenis, disabled under reduced-motion |
| Scroll reveals | all pages | `data-reveal="up\|left\|right\|zoom\|fade"` |
| Line reveal | headings | add `.lu-lines`, split on `<br>` |
| Counters | stats | `<span data-count="140">` |
| Portfolio filter | `portfolio.html` | `data-cat` on items, no dependency |
| Testimonial slider | `index.html` | Swiper, autoplay pauses on interaction |
| Accordion | `faq.html`, `services.html`, `pricing.html` | ARIA-correct, one-open by default |
| Pricing switch | `pricing.html` | `data-monthly` / `data-yearly` |
| Form validation | `contact.html`, `coming-soon.html` | inline errors, `aria-live` status |
| Countdown | `coming-soon.html` | set `data-countdown` to an ISO date |

### Adding a reveal

```html
<div data-reveal>Fades up when it enters the viewport</div>
<div data-reveal="left" style="--d: 120ms">Slides in, 120ms later</div>
```

## Wiring up the contact form

`main.js` validates on the client and then stops — it deliberately does not
post anywhere. To make it live, replace the success branch in `initForms()`
with your own request:

```js
const res = await fetch("/api/contact", {
  method: "POST",
  body: new FormData(form),
});
```

Any endpoint works: a serverless function, Formspree, Basin, your own backend.

## Accessibility

Built in from the start, not bolted on:

- Semantic landmarks (`header`, `nav`, `main`, `footer`, `article`, `aside`)
- Exactly one `<h1>` per page, headings in order
- Skip-to-content link as the first focusable element
- Visible focus rings on every interactive element
- `aria-expanded`, `aria-controls` and `aria-pressed` on all toggles
- `aria-live` status messages on forms
- Full `prefers-reduced-motion` support — reveals, marquees, smooth scroll
  and autoplay all stand down
- Custom cursor hidden on touch and coarse pointers

## Performance

- No framework runtime; roughly 72 KB of unminified template CSS + JS
- Every image is SVG, lazy-loaded, with explicit dimensions
- Fonts are self-hosted woff2, latin subset, preloaded, `font-display: swap`
- `IntersectionObserver` for reveals and counters, not scroll listeners
- Scroll handlers registered as `{ passive: true }`

### Before going live

1. Minify `style.css` and `main.js`
2. Replace `https://example.com` in the meta tags with your real domain
3. Add a real `assets/img/og.jpg` for social sharing
4. `lucide.min.js` ships the full icon set (347 KB). If you only use the
   icons in this template, replace it with inline SVG or a tree-shaken build
5. Re-check Lighthouse on throttled mobile

## Third-party libraries

All **self-hosted** in `assets/vendor/` and `assets/fonts/` — the template
runs with no network connection at all. Regenerate them after upgrading a
dependency with `npm install && node tools/vendor.js`.

| Library | Licence | Used for |
|---|---|---|
| [Bootstrap 5.3](https://github.com/twbs/bootstrap) | MIT | grid and layout utilities |
| [Lenis](https://github.com/darkroomengineering/lenis) | MIT | smooth scrolling |
| [Swiper](https://github.com/nolimits4web/swiper) | MIT | testimonial slider |
| [Lucide](https://github.com/lucide-icons/lucide) | ISC | icons |
| [Syne](https://fonts.google.com/specimen/Syne), [Inter](https://github.com/rsms/inter), [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) | OFL | typography |

Each is optional at runtime: if a script fails to load, the affected feature
degrades and the page still renders and remains navigable.
